# API Reference — islamic-astro

## Core Methods
- `calculate_prayer_times(latitude, longitude, date, timezone, method, asr)`: Computes daily times.
- `calculate_qibla(latitude, longitude)`: Great-Circle bearing and distance to Kaaba.
- `get_next_prayer(latitude, longitude, timezone, method)`: Upcoming prayer with countdown.
- `get_monthly_schedule(latitude, longitude, year, month, timezone)`: Full month calendar.
- `get_ramadan_calendar(latitude, longitude, start_date, total_days)`: Fasting schedule.
